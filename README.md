A one-line review of the dullest everyday object for make.fun's "The Most
Boring Object, Reviewed in One Line" bounty ($2). The line reviews a
doorstop: six years holding the same door open, never thanked, promoted, or
even noticed — five stars, would ignore again. Pure Python standard library,
no network, fully deterministic.

## Run it

```
python3 main.py
```

Writes `entry.txt` to `/output` (`MAKEFUN_OUTPUT_DIR` overrides).
